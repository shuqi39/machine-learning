7.29：机器学习的主要模式分为监督学习和无监督学习，监督学习的主流算法有线性回归和逻辑回归等，无监督学习有k-means聚类，pca等，监督学习指的是既有原始数据x，又有带标签的输出y，目的是预测其他数据x的输出或映射y，具有正确性，无监督学习指的是不带有标签输出的y，只有原始数据x，目的是找出原始数据中的规律，共同点或者一些有意思的东西，正确性是相对的，举个例子，短视频算法中的猜你喜欢是前者，而相似推荐则是后者

7.30：今天系统学习了线性回归，还是初高中的y = w * x + b,但是要看代价j需要^y和w, b画在一张图需要画三维图，方便看j可以引入等高线概念把相同的j给切成平面图，图形复杂则可使用梯度下降算法，就是贪心算法的梯度方向运用

7.31：梯度下降公式：ω = ω - α * dJ(w, b) / dw  
β = β - α * dJ(w, b) / db  
j是最小化代价函数  
α是学习率，就是梯度的步长，太小会导致学习效率太慢，太大的话可能无法收敛  
到达极小值后，偏导数为0，ω会 == ω  
在接近极小值的过程中，步长会越来越小，因为图像越来越缓，偏导数越来越小

8.1：xj表示第j个样本的数据  
->x^(i)表示第i组样本的数据，用列表表示
->x^(i)j表示第i组样本的第j个数据  
python中常用numpy模块引入线性代数  
w = np.array([1.0], [2.0], [3.0])建立数组
np.dot(w, x)或w.dot(x)或干脆w@x为点乘w, x两个数组，因为numpy重载了@作为矩阵乘号  
向量化数据是因为可以调用GPU(图形处理器)进行高效的矩阵运算，以空间换时间  
多重线性回归的梯度下降公式：  
wn = wn - ας(i =1 to m)(f->w, b(->x^(i) - y^(i))) * xn^(i) / m  
b = b - ας(i =1 to m)(f->w, b(->x^(i) - y^(i))) / m  
正规方程：通过高级线代库一次性求解出w, b,无需迭代  
但是它不能推广到其他算法，只适用于多重线性回归算法，而且特征值很多时，其运行速度很慢  
特征缩放：一组样本中不同数据对输出结果的影响可能不一样，比如房子价格中房子大小以及是否有厕所两个数据，特征缩放的意义在于将这些数据归一化，都缩放成0到1，以排除这些因素对特征值和最小化代价函数的影响(本质就是这些数据对应的学习率原来不一样，但将他们缩放成一样)
