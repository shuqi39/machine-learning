7.29：机器学习的主要模式分为监督学习和无监督学习，监督学习的主流算法有线性回归和逻辑回归等，无监督学习有k-means聚类，pca等，监督学习指的是既有原始数据x，又有带标签的输出y，目的是预测其他数据x的输出或映射y，具有正确性，无监督学习指的是不带有标签输出的y，只有原始数据x，目的是找出原始数据中的规律，共同点或者一些有意思的东西，正确性是相对的，举个例子，短视频算法中的猜你喜欢是前者，而相似推荐则是后者

7.30：今天系统学习了线性回归，还是初高中的y = w * x + b,但是要看代价j需要^y和w, b画在一张图需要画三维图，方便看j可以引入等高线概念把相同的j给切成平面图，图形复杂则可使用梯度下降算法，就是贪心算法的梯度方向运用

7.31：梯度下降公式：ω = ω - α * dJ(w, b) / dw  
β = β - α * dJ(w, b) / db  
α是学习率，就是梯度的步长，太小会导致学习效率太慢，太大的话可能无法收敛  
到达极小值后，偏导数为0，ω会 == ω  
在接近极小值的过程中，步长会越来越小，因为图像越来越缓，偏导数越来越小
